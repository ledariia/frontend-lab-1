# Frontend Lab 1

Навчальний проєкт з фронтенд-розробки.
Автор: Дарія Лемеха

## Опис
Містить просту веб-сторінку з адаптивним дизайном, лічильником та перемикачем тем.

## Локальний запуск
1. Склонувати репозиторій.
2. Відкрити файл `index.html` у браузері.

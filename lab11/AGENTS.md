# Правила для AI-агента (ShowFinder)

- **API:** TVmaze (`https://api.tvmaze.com`). Усі запити — GET.
- **CORS:** Не використовуй `mode: 'no-cors'` та не додавай `Content-Type` у GET-запити, це ламає preflight.
- **Пошук:** `/search/shows?q=...`. Використовуй `URLSearchParams` для правильного кодування пробілів. Пошук іде під час введення (debounce 500ms).
- **Сторінка серіалу:** `/shows/{id}?embed[]=episodes&embed[]=cast`. Усі дані завантажуються одним запитом через `embed`.
- **Скасування:** Завжди використовуй `AbortController`. Скасований запит (`AbortError`) — це не помилка, його треба ігнорувати, а не виводити в UI.
- **Помилки HTTP:** Відповіді `!response.ok` (404, 500 тощо) не можна ігнорувати. Кидай помилку зі статусом, щоб обробник міг показати правильне повідомлення.
